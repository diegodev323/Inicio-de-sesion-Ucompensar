# Taller Práctico - App Form (Backend API)

Proyecto backend desarrollado para la gestión y registro de usuarios, proporcionando una API RESTful que se conecta con la aplicación móvil en Android (Kotlin) y almacena la información en una base de datos MySQL/MariaDB.
